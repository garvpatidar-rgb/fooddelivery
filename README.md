# 🍔 Food Delivery App

A full-stack food delivery application built with Go (Gin) backend and React (Vite) frontend.

---

## 🚀 Features

- **User Authentication**: Secure JWT-based registration and login.
- **Restaurant & Menu Browsing**: Explore available food items and restaurants.
- **Cart & Order Management**: Add items to cart and place orders.
- **Admin Dashboard**: Manage dishes, orders, and restaurants.

---

## 🛠 Tech Stack

- **Backend**: Go, Gin Web Framework, PostgreSQL / GORM, JWT
- **Frontend**: React, Vite, Tailwind CSS / Vanilla CSS, React Router, React Hot Toast
- **DevOps**: Docker, GitHub Actions CI

---

## 📦 Getting Started

### 1. Prerequisites
- [Go](https://go.dev/) (1.20+)
- [Node.js](https://nodejs.org/) (v18+)
- [PostgreSQL](https://www.postgresql.org/)

### 2. Backend Setup
```bash
cd backend
go mod download
go run main.go
```

### 3. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
